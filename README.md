## ✨ Tentang proyek ini

Sebuah hadiah ulang tahun digital, dibangun sebagai perjalanan 20 babak — mulai dari
sambutan, puzzle kecil, ruang untuk melepas beban lewat tulisan, kapsul waktu ke masa
depan, bilik foto dengan bingkai custom, sampai sertifikat penutup. Semuanya berjalan
di satu halaman, ditemani playlist musik latar.

---

## 🛠️ Dibangun dengan

- **HTML, CSS, JavaScript murni** — tanpa framework, tanpa build step
- **Firebase Firestore** untuk fitur real-time (chat, status kunjungan)
- **GitHub Pages** untuk hosting

---

## 📁 Struktur folder

```
├── index.html          situs utama
├── styles.css          semua CSS
├── script.js           semua JavaScript
├── README.md
└── assets/
    ├── audio/           playlist musik latar
    ├── frames/          template bingkai photobooth
    └── og-preview.jpg   gambar preview saat link dibagikan
```

---

## 🚀 Menjalankan secara lokal

```bash
git clone https://github.com/3rizqmlna/adalahpokoknya.git
cd adalahpokoknya
```

Lalu buka `index.html` langsung di browser, atau layani lewat local server ringan
(disarankan, supaya semua fitur berjalan normal):

```bash
npx serve .
```
